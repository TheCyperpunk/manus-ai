# Global Loader and Proof Surface Validation

## Initial app loader

- The document-level Source Atlas loader starts before React mounts and is visible only on the first visit.
- It hands off to the existing Overview rather than adding a second persistent overlay.
- Motion-sensitive users receive the static, reduced-motion behavior.

## Desktop proof surface

- The Overview desktop viewport renders the GitHub-backed build trace beside the hero portrait without displacing the existing hero copy, actions, social controls, or dossier geometry.
- The terminal reports the public handle, repository index, interface / AI / Web3 build focus, and a live source state.
- TypeScript validation and the production build completed successfully after the loader and proof-surface changes.

## Mobile proof surface

At 375 px width, the hero remains readable in sequence: role, explanation, source terminal, primary action, public-trail action, social controls, and then the personal dossier. The terminal preserves its compact signal hierarchy without horizontal overflow or overlap with the monogram field.
